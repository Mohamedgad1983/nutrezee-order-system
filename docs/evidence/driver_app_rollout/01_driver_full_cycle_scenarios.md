## 5. الأولويات قبل تسليم التطبيق (توصيتي بالترتيب)

1. **حالة "لم يتم التسليم" بأسباب + "مرتجع للمطبخ"** في Order Config (إعدادات، بلا vendor)، مع تعديل cron A29 ليستثنيها ويقفل المبدوء المنسي (C3, E2).
2. **تبسيط التدفق** إلى ضغطة تسليم واحدة أو ضغطتين (R1/R2)، وتدريب السائقين: "لا يبقى طلب dispatched في نهاية اليوم".
3. **إثبات صورة عند التسليم في bin** (C2) — قرار المالك.
4. **تنبيه العمليات** للإلغاء بعد Start (R5) ولطلبات نفس اليوم المضافة بعد 01:45 (K9).
5. **تسجيل webhook Fleetbase → Nutrezee** لتقارير التسليم (F6).
6. **استهلاك مواقع السائقين الملتقطة** في اليوم التالي (F8) — يحتاج قرار A30.
7. عدّاد الاستلام في المطبخ (K1) وقائمة "ملغي بعد الطباعة" للمطبخ (K4).
8. اختبار ميداني بوضع الطيران لتحديث النشاط (R6) وإجراء OTP الطوارئ (K7).
